ContextDomain, law, affected groups

Context decides which metric fits (step 1) and how results are judged (step 3). It is recorded with the plan; if any of it changes, return here and re-assess.

CWhat does the case data contain?

The §7 metrics compare rates of a two-way decision (positive / negative), so every output is turned into one: a numeric output (score, probability, rank, continuous value) with a threshold, or a decision or category with the value(s) that count as positive. This follows the classification and regression scope of ISO/IEC TS 12791. Measurability depends on the data you have, not only on the bias. Use the exact column names of the CSV you will upload.
