Stage B — confirm the bias list. Every question asks whether a bias is present in this system. Answer Confirmed (yes, there is evidence it is present), Not present (there is evidence it is not) or Unknown (it has not been checked, there is no information, or you have no authority to answer). Add evidence for every status. Confirmed biases move on to the Metric plan, where you decide which ones can be measured and how.

Who answers? The checklist is general; each item is answered by whoever has the authority to know — the API provider (e.g. training data, model design) or the API consumer (e.g. use in context). If the provider cannot take part (e.g. a third-party LLM), cite public documentation such as model or system cards as evidence, or mark the item Unknown — no authority. The tag on each item shows the standard and clause it comes from.
